# Sistema de Ventas – VENTAS MERCEDES

Sistema web de gestión de ventas desarrollado en PHP utilizando la arquitectura MVC (Modelo, Vista y Controlador).

## Funcionalidades

- Gestión de artículos.
- Gestión de categorías.
- Registro de compras.
- Gestión de proveedores.
- Gestión de clientes.
- Registro de ventas.
- Gestión de usuarios y permisos.
- Panel principal del sistema.

## Tecnologías utilizadas

- PHP
- MySQL
- JavaScript
- jQuery
- AJAX
- Bootstrap
- AdminLTE

## Estructura del proyecto

- `ajax/`: procesos asíncronos.
- `config/`: configuración y conexión.
- `modelos/`: lógica y consultas.
- `vistas/`: interfaces del sistema.
- `public/`: archivos CSS, JavaScript e imágenes.

## Instalación

1. Instalar XAMPP.
2. Copiar el proyecto dentro de la carpeta `htdocs`.
3. Iniciar Apache y MySQL.
4. Crear la base de datos e importar el archivo SQL correspondiente.
5. Configurar la conexión en los archivos de `config/`.
6. Abrir el sistema desde el navegador.
